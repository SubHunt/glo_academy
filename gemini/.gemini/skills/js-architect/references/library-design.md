# Гайд по проектированию JS-библиотек

## Структура проекта
- `src/`: Исходный код.
- `dist/`: Скомпилированные файлы.
- `tests/`: Модульные и интеграционные тесты.
- `docs/`: Документация и примеры.

## Поддержка различных форматов (Universal Library)
- **ESM (`.mjs`):** Современный стандарт.
- **UMD/IIFE:** Для прямого подключения через `<script>`.
- **CJS:** Для Node.js окружения.

## Проектирование API
- **Минимализм:** Предоставляйте только необходимые методы.
- **Предсказуемость:** Используйте интуитивно понятные названия и структуры данных.
- **Расширяемость:** Позволяйте пользователям настраивать поведение через конфиги или хуки.

## Управление состоянием
- Избегайте глобального состояния, если это возможно.
- Используйте неизменяемость (Immutability) для предотвращения побочных эффектов.
