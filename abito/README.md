# Abito - Доска объявлений

Простая доска объявлений, разработанная с использованием HTML, CSS и JavaScript.

## О проекте

Abito - это веб-приложение для размещения и просмотра объявлений. Проект включает в себя основные компоненты пользовательского интерфейса и готов к дальнейшей разработке с использованием React.

## Технологии

- HTML
- CSS
- JavaScript
- React (в планах)

## Структура проекта

```
abito/
├── index.html
├── style.css
├── image/
│   ├── burger.svg
│   └── logo.svg
└── README.md
```

## Особенности

- Адаптивный дизайн
- Кнопки входа и регистрации
- Возможность подачи объявлений
- Мобильная навигация (бургер-меню)

## Установка

1. Клонируйте репозиторий
2. Откройте `index.html` в браузере
